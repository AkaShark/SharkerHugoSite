## 第一轮四篇（建议每两周一篇，不设硬性发布日期）

1. **KVO / KVC：从一个可运行示例开始**：把现有占位稿补成完整文章。验收：代码、调用顺序、适用范围。
2. **WKWebView 导航问题排查**：延续已有 User-Agent 文章，从一个真实问题展开。验收：复现步骤、诊断、修复前后比较。
3. **Go context：取消与超时如何传递**：作为 Go 系列后续。验收：一个并发示例与测试结果。
4. **《图解 HTTP》：三个概念与一次抓包**：把空白阅读笔记补完。验收：原书观点、自己的理解、实际观察。

如果没有真实案例，就保留选题，不编造项目经历或实验结果。

## 长期主线

- **iOS 实践**：问题复现 → 原理 → 修复 → 验证。积累能被以后自己复用的排查记录。

- **网络与系统**：用抓包、命令或小实验讲清 HTTP 和操作系统概念。
- **阅读与生活**：减少摘抄堆积，每篇围绕一个问题，加上个人理解或可执行行动。
